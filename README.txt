# NopalColors — Landing page

## Para subirla a GitHub Pages

1. Sube `index.html`, `style.css`, `script.js` y la carpeta `img`.
2. Dentro de `img` deja `logo.png` y `mascota.png`.
3. Agrega tus tres fotos con estos nombres exactos:
   - `producto-1.jpg`
   - `producto-2.jpg`
   - `producto-3.jpg`
4. En `index.html`, busca `TU_CORREO_AQUI` y reemplázalo por el correo real.
5. En GitHub: Settings → Pages → Deploy from a branch → selecciona la rama donde subiste los archivos.

## Si quieres conservar la URL actual

Puedes reemplazar los archivos de tu repositorio actual de NopalColors con estos. No necesitas crear otro repositorio.

Las tres fotos están pensadas como:
- Foto 1: kit completo
- Foto 2: contenido
- Foto 3: uso/aplicación

Puedes cambiar los textos de las tres leyendas directamente en `index.html`.
